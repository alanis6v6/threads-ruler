# 翠排版尺

Threads（翠）串文排版預覽工具：直接在預覽裡寫，照 Threads 實際量到的寬度看每一行在哪裡換行。

- 串文列表／點開貼文、電腦／手機切換
- 空白行保留（複製時塞入 U+2800 點字空白）
- 半形空白自動轉全形、選取段落置中
- 英文特殊字體、顏文字一鍵換臉換手勢

網站：https://alanis6v6.github.io/threads-ruler/
