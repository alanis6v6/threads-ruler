# Chrome 線上應用程式商店上架資料

在 [Chrome 線上應用程式商店開發人員資訊主頁](https://chrome.google.com/webstore/devconsole) 填寫時，照下面各欄位複製貼上。

---

## 1. 上傳套件

1. 在 repo 資料夾執行 `./scripts/pack-extension.sh`，產生 `dist/threads-ruler-extension.zip`。
2. 開發人員資訊主頁 → 左上 **＋ 新增項目** → 選 `threads-ruler-extension.zip` 上傳。

---

## 2. 商店資訊（Store listing）

### 說明（Description）

```
照翠（Threads）實際的寬度排版串文，直接在預覽裡寫，看每一行在哪裡換行。

翠的串文列表、點開貼文、電腦版、手機版，文字寬度都不一樣：同一段話換到不同版型，換行位置就跑掉了。翠排版尺依實際量測的寬度即時預覽，讓你發文前就知道讀者看到的樣子。

【功能】
・串文列表／點開貼文、電腦／手機（360、390、430）一鍵切換，顯示每行大約幾個字
・直接在預覽裡打字編輯，字數、行數即時計算
・保留空白行：複製時自動塞入看不見的點字空白，段落間距不會被吃掉
・半形空白自動轉全形：連續或行首的半形空白不會被翠縮掉
・選取段落一鍵置中（可選兩邊折衷／只顧列表／只顧點開）
・英文特殊字體：粗體、草寫、哥德、空心、打字機等 14 種，點一下就換
・顏文字一鍵換臉、換手勢，懶得挑就擲骰子
・多則串文、復原、複製全文、第一次使用導覽

【怎麼用】
點工具列上的翠排版尺圖示，右側打開側邊欄；左邊開著翠，右邊排版。
在翠按「有什麼新鮮事？」打開發文視窗後，按「填入整串」，排好的串文會直接填進發文框（第二則起自動按「新增到串文」），確認後自己按發佈。
翠的發文視窗旁邊還會出現「翠排版尺」工具卡，直接在發文框裡選取文字置中、換英文字體、換顏文字，發佈前一鍵整理空白行和空白。
不會替你發文，也不讀取貼文、留言或私訊。

【隱私】
不收集任何資料。草稿只存在你自己的瀏覽器裡，不上傳到任何伺服器。

網頁版（手機也能用）：https://alanis6v6.github.io/threads-ruler/
作者：Threads @space.grapefruit_
授權：PolyForm Noncommercial 1.0.0（禁止商業用途，修改或轉載版本須在畫面上保留原作者署名）
```

## 3. 隱私權實務（Privacy practices）

### 單一用途說明

```
在 Chrome 側邊欄提供 Threads（翠）串文排版工具：依 Threads 實際的文字寬度，即時顯示串文在串文列表、點開貼文、電腦與手機版中的換行位置，協助調整空白、置中、英文字體與顏文字，並在使用者按下按鈕時把排好的文字填進 Threads 發文框（不會自動發文）。
```

### 權限理由

**sidePanel**

```
使用者點擊工具列圖示時，在 Chrome 側邊欄開啟排版工具，讓使用者可以一邊瀏覽 Threads、一邊排版串文。
```

**clipboardWrite**

```
使用者按下「複製」或「複製全文」時，將排版好的串文文字寫入剪貼簿，方便貼到 Threads 發文。只在使用者點擊按鈕時寫入，不讀取剪貼簿內容。
```

**storage**

```
使用者在 Threads 發文視窗旁按「用翠排版尺排版」時，把發文框裡的文字暫存到 chrome.storage.session，交給側邊欄讀取；側邊欄讀取後立即刪除，不做其他用途。
```

**主機權限（https://www.threads.com/*、https://www.threads.net/*）**

```
在 Threads 發文視窗旁加入「翠排版尺」工具卡，並在使用者按下工具卡按鈕（置中、換字體、換顏文字、發佈前整理）或側邊欄的「填入」時，改寫或填入 Threads 發文框裡的文字。只在使用者點擊按鈕時讀寫發文框文字，不讀取貼文、留言、私訊等其他內容，不會自動發文，也不會傳送任何資料到外部伺服器。
```
